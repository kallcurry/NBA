## 安装

手机允许“安装未知来源应用”后直接打开 APK，或：

```bash
adb install -r courtside-1.1.2.apk
```

已安装旧版本可以直接覆盖安装，数据会保留。

## 通知

1. 打开 App → 设置 → 通知，开启通知。
2. Android 13+ 允许通知权限。
3. Android 12+ 建议允许“闹钟和提醒”，保证准时提醒。
4. **切换到明天/未来日期，给一场未开赛的比赛点铃铛**；今天所有比赛都结束后是不会有开赛提醒的。
5. 关闭 App 后，到点会收到系统通知。

这是本地定时提醒；实时比分推送需要 FCM 服务端推送。

## 状态栏没有图标？

只有到提醒时间才会出现通知，不会常驻状态栏。先点“发一条测试通知”确认权限和通知渠道是否正常。

## 数据

APK 直接访问 `site.web.api.espn.com`，不需要在手机上运行 Node 服务。若手机网络无法访问 ESPN，数据会加载失败，请改用 Node 服务版本或配置可访问的代理。
